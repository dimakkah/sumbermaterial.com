Cara Hitung Luas Rangka Baja Ringan Di Setu Bekasi

Anda bisa melakukan perhitungan sendiri jika mau dikerjakan utk mengenal harga serta kemiringan atap. Berikut yakni rumus perhitunganya. Memutuskan kemiringan atap Apabila panjang rangka atap sekitar 15 ml, meskipun utk lebar ialah 10 ml, utk overstack 0.60 m, kemiripan atap sekitar 30 derajat ( cosinus 30 = 0.8660) dg wujud atap limas ( jatuh air dari ke empat sisi ).

Menetapkan luas datar

Perhitungan luas datar yaitu ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya yaitu ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yg akan didapatkan disini yaitu 16.2 x 11.2 dg hasil luas datar : 181.44 meter.

Memastikan Luas miring

Penentuan luas miring untuk perhitungannya merupakan Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 menjadikan 209.52 meter persegi. Jadi untuk luas kemiringan pada rangka atap baja ringan ini ialah 209.52 m2.

Dengan seperti itu anda dapat mempertimbangkan jumlah dan volume baja ringan untuk pemesangan, tetapi jikalau terlihat sulit utk dijalankan.
