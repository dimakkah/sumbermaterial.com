Menentukan kemiringan atap Seandainya panjang rangka atap sekitar 15 ml, meski untuk lebar ialah 10 ml, untuk overstack 0.60 m, kemiripan atap sekitar 30 derajat ( cosinus 30 = 0.8660) dengan format atap limas ( jatuh air dari ke empat sisi ).

Menentukan luas datar

Perhitungan luas datar yakni ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya yakni ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Maka hasil yg akan didapatkan disini yaitu 16.2 x 11.2 dengan hasil luas datar : 181.44 meter persegi.

Mempertimbangkan Luas miring

Penentuan luas miring untuk perhitungannya ialah Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 mewujudkan 209.52 meter persegi. Jadi utk luas kemiringan pada rangka atap baja ringan ini yaitu 209.52 m2.
