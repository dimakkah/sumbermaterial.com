Sistem Hitung Luas Rangka Baja Ringan Di Pasar Manggis Jakarta

Anda bisa menjalankan perhitungan sendiri jikalau mau dijalankan untuk mengenal harga serta kemiringan atap. Berikut yakni rumus perhitunganya. Menetapkan kemiringan atap Bila panjang rangka atap sekitar 15 ml, sedangkan utk lebar yaitu 10 ml, untuk overstack 0.60 m, kemiripan atap sekitar 30 derajat ( cosinus 30 = 0.8660) dengan format atap limas ( jatuh air dari ke empat sisi ).

Memastikan luas datar

Perhitungan luas datar ialah ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya merupakan ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Maka hasil yang akan diperoleh disini yakni 16.2 x 11.2 dg hasil luas datar : 181.44 m2.

Mempertimbangkan Luas miring

Penentuan luas miring untuk perhitungannya yakni Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 menjadikan 209.52 m2. Jadi utk luas kemiringan pada rangka atap baja ringan ini ialah 209.52 meter persegi.

Dengan semacam itu anda dapat menentukan jumlah dan volume baja ringan untuk pemesangan, tetapi sekiranya kelihatan sulit utk dilakukan.
