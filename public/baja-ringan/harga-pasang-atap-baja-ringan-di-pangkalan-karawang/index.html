Menentukan kemiringan atap Bila panjang rangka atap sekitar 15 ml, meskipun untuk lebar yaitu 10 ml, utk overstack 0.60 m, kemiripan atap sekitar 30 derajat ( cosinus 30 = 0.8660) dg format atap limas ( jatuh air dari ke empat sisi ).

Menetapkan luas datar

Perhitungan luas datar ialah ( overstack + Panjang ) x ( lebar + overstack ) karenanya hasilya yakni ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yang akan diperoleh disini merupakan 16.2 x 11.2 dg hasil luas datar : 181.44 meter persegi.

Mempertimbangkan Luas miring

Penentuan luas miring untuk perhitungannya ialah Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 mewujudkan 209.52 meter. Jadi untuk luas kemiringan pada rangka atap baja ringan ini yakni 209.52 meter.
