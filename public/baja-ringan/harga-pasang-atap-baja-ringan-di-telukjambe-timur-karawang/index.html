Menentukan kemiringan atap Jikalau panjang rangka atap sekitar 15 ml, sedangkan utk lebar yakni 10 ml, untuk overstack 0.60 m, kemiripan atap sekitar 30 derajat ( cosinus 30 = 0.8660) dengan format atap limas ( jatuh air dari ke empat sisi ).

Menetapkan luas datar

Perhitungan luas datar merupakan ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya ialah ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Maka hasil yang akan didapatkan disini adalah 16.2 x 11.2 dengan hasil luas datar : 181.44 meter.

Memutuskan Luas miring

Penentuan luas miring untuk perhitungannya ialah Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 mewujudkan 209.52 meter. Jadi untuk luas kemiringan pada rangka atap baja ringan ini yaitu 209.52 meter persegi.
