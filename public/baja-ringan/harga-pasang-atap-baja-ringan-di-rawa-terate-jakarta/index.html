Memutuskan kemiringan atap Sekiranya panjang rangka atap sekitar 15 ml, meski untuk lebar merupakan 10 ml, untuk overstack 0.60 m, kemiripan atap sekitar 30 derajat ( cosinus 30 = 0.8660) dengan format atap limas ( jatuh air dari ke empat sisi ).

Memastikan luas datar

Perhitungan luas datar adalah ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya ialah ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Maka hasil yang akan didapat disini yaitu 16.2 x 11.2 dengan hasil luas datar : 181.44 meter.

Menentukan Luas miring

Penentuan luas miring untuk perhitungannya merupakan Luas miring = Luas datar / Cosinus dg kemiringan atap. Perhitungannya 181.44/0.8666 menciptakan 209.52 meter persegi. Jadi untuk luas kemiringan pada rangka atap baja ringan ini ialah 209.52 m2.
