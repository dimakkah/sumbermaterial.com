Cara Hitung Luas Rangka Baja Ringan Di Johar Baru Jakarta

Anda dapat menjalankan perhitungan sendiri sekiranya mau dikerjakan utk mengetahui harga serta kemiringan atap. Berikut adalah rumus perhitunganya. Menentukan kemiringan atap Seandainya panjang rangka atap sekitar 15 ml, meskipun untuk lebar yaitu 10 ml, untuk overstack 0.60 m, kemiripan atap sekitar 30 derajat ( cosinus 30 = 0.8660) dengan format atap limas ( jatuh air dari ke empat sisi ).

Mempertimbangkan luas datar

Perhitungan luas datar yaitu ( overstack + Panjang ) x ( lebar + overstack ) karenanya hasilya yakni ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yg akan didapat disini yakni 16.2 x 11.2 dg hasil luas datar : 181.44 meter persegi.

Menentukan Luas miring

Penentuan luas miring untuk perhitungannya ialah Luas miring = Luas datar / Cosinus dg kemiringan atap. Perhitungannya 181.44/0.8666 menjadikan 209.52 meter. Jadi utk luas kemiringan pada rangka atap baja ringan ini yakni 209.52 meter.

Dengan begitu anda dapat menetapkan jumlah dan volume baja ringan untuk pemesangan, namun jikalau tampak susah untuk dijalankan.
