Memutuskan kemiringan atap Bila panjang rangka atap sekitar 15 ml, meskipun untuk lebar yaitu 10 ml, untuk overstack 0.60 m, kemiripan atap sekitar 30 derajat ( cosinus 30 = 0.8660) dg bentuk atap limas ( jatuh air dari ke empat sisi ).

Menetapkan luas datar

Perhitungan luas datar yakni ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya merupakan ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yg akan didapatkan disini yakni 16.2 x 11.2 dg hasil luas datar : 181.44 m2.

Menetapkan Luas miring

Penentuan luas miring untuk perhitungannya yaitu Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 menjadikan 209.52 meter. Jadi untuk luas kemiringan pada rangka atap baja ringan ini ialah 209.52 meter persegi.
