Anda dapat melakukan perhitungan sendiri jika ingin dijalankan utk mengetahui biaya serta kemiringan atap. Berikut yakni rumus perhitunganya. Mempertimbangkan kemiringan atap Sekiranya panjang rangka atap sekitar 15 ml, sedangkan untuk lebar merupakan 10 ml, untuk overstack 0.60 m, kemiripan atap sekitar 30 derajat ( cosinus 30 = 0.8660) dg bentuk atap limas ( jatuh air dari ke empat sisi ).

Menentukan luas datar

Perhitungan luas datar ialah ( overstack + Panjang ) x ( lebar + overstack ) karenanya hasilya merupakan ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Maka hasil yg akan didapatkan disini adalah 16.2 x 11.2 dengan hasil luas datar : 181.44 m2.

Menetapkan Luas miring

Penentuan luas miring utk perhitungannya adalah Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 menghasilkan 209.52 meter persegi. Jadi untuk luas kemiringan pada rangka atap baja ringan ini merupakan 209.52 m2.

Dengan semacam itu anda dapat memastikan jumlah dan volume baja ringan untuk pemesangan, namun kalau menonjol sulit utk dilakukan.
