Memutuskan luas datar

Perhitungan luas datar yaitu ( overstack + Panjang ) x ( lebar + overstack ) karenanya hasilya yaitu ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yg akan diperoleh disini yaitu 16.2 x 11.2 dg hasil luas datar : 181.44 meter persegi.

Mempertimbangkan Luas miring

Penentuan luas miring untuk perhitungannya merupakan Luas miring = Luas datar / Cosinus dg kemiringan atap. Perhitungannya 181.44/0.8666 mewujudkan 209.52 meter persegi. Jadi utk luas kemiringan pada rangka atap baja ringan ini yakni 209.52 m2.
