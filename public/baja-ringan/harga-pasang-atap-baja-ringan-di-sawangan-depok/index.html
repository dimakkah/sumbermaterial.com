Sistem Hitung Luas Rangka Baja Ringan Di Sawangan Depok

Anda bisa melakukan perhitungan sendiri kalau ingin dijalankan untuk mengetahui harga serta kemiringan atap. Berikut ialah rumus perhitunganya. Menetapkan kemiringan atap Sekiranya panjang rangka atap sekitar 15 ml, sedangkan untuk lebar yakni 10 ml, untuk overstack 0.60 m, kemiripan atap sekitar 30 derajat ( cosinus 30 = 0.8660) dengan format atap limas ( jatuh air dari ke empat sisi ).

Menentukan luas datar

Perhitungan luas datar yaitu ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya yakni ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Maka hasil yg akan didapatkan disini adalah 16.2 x 11.2 dg hasil luas datar : 181.44 m2.

Mempertimbangkan Luas miring

Penentuan luas miring untuk perhitungannya ialah Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 menjadikan 209.52 meter. Jadi utk luas kemiringan pada rangka atap baja ringan ini yakni 209.52 meter.

Dengan begitu anda bisa menetapkan jumlah dan volume baja ringan utk pemesangan, tapi apabila kelihatan sulit untuk dikerjakan.
