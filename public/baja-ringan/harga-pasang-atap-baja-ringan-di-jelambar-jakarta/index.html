Menetapkan kemiringan atap Apabila panjang rangka atap sekitar 15 ml, sedangkan untuk lebar merupakan 10 ml, untuk overstack 0.60 m, kemiripan atap sekitar 30 derajat ( cosinus 30 = 0.8660) dg wujud atap limas ( jatuh air dari ke empat sisi ).

Menentukan luas datar

Perhitungan luas datar adalah ( overstack + Panjang ) x ( lebar + overstack ) karenanya hasilya merupakan ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Maka hasil yg akan diperoleh disini ialah 16.2 x 11.2 dg hasil luas datar : 181.44 m2.

Memutuskan Luas miring

Penentuan luas miring utk perhitungannya merupakan Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 mewujudkan 209.52 meter persegi. Jadi utk luas kemiringan pada rangka atap baja ringan ini yakni 209.52 m2.
