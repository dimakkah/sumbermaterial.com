Cara Hitung Luas Rangka Baja Ringan Di Petogogan Jakarta

Anda dapat mengerjakan perhitungan sendiri sekiranya berharap dilaksanakan untuk mengenal biaya serta kemiringan atap. Berikut merupakan rumus perhitunganya. Memastikan kemiringan atap Seandainya panjang rangka atap sekitar 15 ml, sedangkan utk lebar yaitu 10 ml, untuk overstack 0.60 m, kemiripan atap sekitar 30 derajat ( cosinus 30 = 0.8660) dengan bentuk atap limas ( jatuh air dari ke empat sisi ).

Menentukan luas datar

Perhitungan luas datar adalah ( overstack + Panjang ) x ( lebar + overstack ) karenanya hasilya merupakan ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Maka hasil yg akan diperoleh disini merupakan 16.2 x 11.2 dengan hasil luas datar : 181.44 meter persegi.

Memastikan Luas miring

Penentuan luas miring untuk perhitungannya yaitu Luas miring = Luas datar / Cosinus dg kemiringan atap. Perhitungannya 181.44/0.8666 mewujudkan 209.52 meter persegi. Jadi untuk luas kemiringan pada rangka atap baja ringan ini merupakan 209.52 m2.

Dengan demikian itu anda dapat menentukan jumlah dan volume baja ringan untuk pemesangan, namun apabila kelihatan susah untuk dikerjakan.
