Cara Hitung Luas Rangka Baja Ringan Di Manggarai Selatan Jakarta

Anda bisa menjalankan perhitungan sendiri sekiranya mau dilakukan untuk mengetahui harga serta kemiringan atap. Berikut adalah rumus perhitunganya. Memastikan kemiringan atap Bila panjang rangka atap sekitar 15 ml, meski untuk lebar merupakan 10 ml, untuk overstack 0.60 m, kemiripan atap sekitar 30 derajat ( cosinus 30 = 0.8660) dg wujud atap limas ( jatuh air dari ke empat sisi ).

Memastikan luas datar

Perhitungan luas datar yakni ( overstack + Panjang ) x ( lebar + overstack ) karenanya hasilya ialah ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Maka hasil yg akan diperoleh disini yakni 16.2 x 11.2 dg hasil luas datar : 181.44 m2.

Menetapkan Luas miring

Penentuan luas miring utk perhitungannya yaitu Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 menciptakan 209.52 meter. Jadi untuk luas kemiringan pada rangka atap baja ringan ini yakni 209.52 meter.

Dengan seperti itu anda dapat memutuskan jumlah dan volume baja ringan untuk pemesangan, tapi seandainya kelihatan sulit utk dilaksanakan.
