### Menghitung Luas Datar

Perhitungan luas datar adalah ( *overstack* + Panjang ) x ( lebar + *overstack* ). Jadi, ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ) = 16.2 x 11.2 = 181.44 meter persegi.

### Menghitung Luas Miring

Luas miring dihitung dengan rumus: Luas miring = Luas datar / Cosinus kemiringan atap. Jadi, 181.44 / 0.8666 = 209.52 m². Dengan demikian, luas kemiringan rangka atap baja ringan adalah 209.52 meter persegi.
