Perhitungan luas datar yakni ( overstack + Panjang ) x ( lebar + overstack ) karenanya hasilya yakni ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yang akan didapat disini merupakan 16.2 x 11.2 dg hasil luas datar : 181.44 meter persegi.

### Mempertimbangkan Luas miring

Penentuan luas miring untuk perhitungannya yaitu Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 menghasilkan 209.52 m2. Jadi utk luas kemiringan pada rangka atap baja ringan ini adalah 209.52 meter.
