## Sistem Hitung Luas Rangka Baja Ringan Di Limo Depok

Anda dapat melaksanakan perhitungan sendiri apabila berharap dikerjakan utk mengetahui harga serta kemiringan atap. Berikut adalah rumus perhitunganya. Mempertimbangkan kemiringan atap Sekiranya panjang rangka atap sekitar 15 ml, sedangkan utk lebar ialah 10 ml, untuk overstack 0.60 m, kemiripan atap sekitar 30 derajat ( cosinus 30 = 0.8660) dengan format atap limas ( jatuh air dari ke empat sisi ).

### Mempertimbangkan luas datar

Perhitungan luas datar merupakan ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya ialah ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yg akan didapatkan disini merupakan 16.2 x 11.2 dg hasil luas datar : 181.44 meter.

### Menentukan Luas miring

Penentuan luas miring untuk perhitungannya ialah Luas miring = Luas datar / Cosinus dg kemiringan atap. Perhitungannya 181.44/0.8666 mewujudkan 209.52 meter persegi. Jadi untuk luas kemiringan pada rangka atap baja ringan ini yakni 209.52 meter.

Dengan semacam itu anda dapat menetapkan jumlah dan volume baja ringan untuk pemesangan, tetapi bila menonjol sulit utk dilaksanakan.
