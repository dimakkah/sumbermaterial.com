### Mempertimbangkan luas datar

Perhitungan luas datar merupakan ( overstack + Panjang ) x ( lebar + overstack ) karenanya hasilya merupakan ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yg akan didapat disini ialah 16.2 x 11.2 dengan hasil luas datar : 181.44 m2.

### Menentukan Luas miring

Penentuan luas miring utk perhitungannya ialah Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 menghasilkan 209.52 m2. Jadi utk luas kemiringan pada rangka atap baja ringan ini adalah 209.52 meter.
