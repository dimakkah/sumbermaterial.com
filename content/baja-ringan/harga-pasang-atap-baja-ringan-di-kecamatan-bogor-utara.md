### Menentukan luas datar

Perhitungan luas datar yaitu ( overstack + Panjang ) x ( lebar + overstack ) karenanya hasilya ialah ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Maka hasil yg akan diperoleh disini yakni 16.2 x 11.2 dg hasil luas datar : 181.44 meter.

### Memastikan Luas miring

Penentuan luas miring untuk perhitungannya adalah Luas miring = Luas datar / Cosinus dg kemiringan atap. Perhitungannya 181.44/0.8666 menjadikan 209.52 meter. Jadi untuk luas kemiringan pada rangka atap baja ringan ini yakni 209.52 m2.
