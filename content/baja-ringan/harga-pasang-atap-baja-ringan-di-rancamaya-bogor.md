Perhitungan luas datar adalah ( *overstack* + Panjang ) x ( lebar + *overstack* ) = ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ) = 16.2 x 11.2 dengan hasil luas datar : 181.44 meter persegi.
