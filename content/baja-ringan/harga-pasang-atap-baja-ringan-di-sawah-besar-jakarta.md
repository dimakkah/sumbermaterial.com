### Memutuskan luas datar

Perhitungan luas datar merupakan ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya yaitu ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yang akan diperoleh disini merupakan 16.2 x 11.2 dengan hasil luas datar : 181.44 meter persegi.

### Menentukan Luas miring

Penentuan luas miring untuk perhitungannya yakni Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 mewujudkan 209.52 meter persegi. Jadi utk luas kemiringan pada rangka atap baja ringan ini yakni 209.52 m2.
