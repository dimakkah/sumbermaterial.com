### Memutuskan luas datar

Perhitungan luas datar merupakan ( overstack + Panjang ) x ( lebar + overstack ) karenanya hasilya adalah ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yang akan didapatkan disini adalah 16.2 x 11.2 dg hasil luas datar : 181.44 meter persegi.

### Mempertimbangkan Luas miring

Penentuan luas miring untuk perhitungannya yaitu Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 mewujudkan 209.52 meter. Jadi untuk luas kemiringan pada rangka atap baja ringan ini yaitu 209.52 meter persegi.
