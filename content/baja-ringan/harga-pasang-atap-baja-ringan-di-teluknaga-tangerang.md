### Memutuskan luas datar

Perhitungan luas datar adalah ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya merupakan ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yang akan diperoleh disini yaitu 16.2 x 11.2 dg hasil luas datar : 181.44 meter persegi.

### Menetapkan Luas miring

Penentuan luas miring untuk perhitungannya ialah Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 menciptakan 209.52 meter persegi. Jadi utk luas kemiringan pada rangka atap baja ringan ini adalah 209.52 m2.
