### Memutuskan luas datar

Perhitungan luas datar ialah ( overstack + Panjang ) x ( lebar + overstack ) karenanya hasilya ialah ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yg akan diperoleh disini yaitu 16.2 x 11.2 dengan hasil luas datar : 181.44 meter persegi.

### Memastikan Luas miring

Penentuan luas miring untuk perhitungannya merupakan Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 menciptakan 209.52 meter. Jadi utk luas kemiringan pada rangka atap baja ringan ini adalah 209.52 meter.
