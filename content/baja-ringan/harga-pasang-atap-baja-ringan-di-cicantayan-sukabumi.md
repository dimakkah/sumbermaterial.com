### Menetapkan luas datar

Perhitungan luas datar yaitu ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya yakni ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Maka hasil yg akan diperoleh disini yaitu 16.2 x 11.2 dengan hasil luas datar : 181.44 meter persegi.

### Menentukan Luas miring

Penentuan luas miring untuk perhitungannya ialah Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 menghasilkan 209.52 m2. Jadi utk luas kemiringan pada rangka atap baja ringan ini yaitu 209.52 meter.
