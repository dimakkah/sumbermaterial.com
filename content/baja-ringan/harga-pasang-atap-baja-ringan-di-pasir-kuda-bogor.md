Perhitungan luas datar yakni ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya merupakan ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Maka hasil yang akan diperoleh disini adalah 16.2 x 11.2 dg hasil luas datar : 181.44 m2.

Penentuan luas miring utk perhitungannya merupakan Luas miring = Luas datar / Cosinus dg kemiringan atap. Perhitungannya 181.44/0.8666 menjadikan 209.52 meter. Jadi untuk luas kemiringan pada rangka atap baja ringan ini ialah 209.52 meter persegi.
