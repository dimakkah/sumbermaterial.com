### Memastikan luas datar

Perhitungan luas datar yakni ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya merupakan ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yang akan didapat disini ialah 16.2 x 11.2 dg hasil luas datar : 181.44 meter persegi.

### Memastikan Luas miring

Penentuan luas miring untuk perhitungannya ialah Luas miring = Luas datar / Cosinus dg kemiringan atap. Perhitungannya 181.44/0.8666 menghasilkan 209.52 m2. Jadi untuk luas kemiringan pada rangka atap baja ringan ini yaitu 209.52 meter.
