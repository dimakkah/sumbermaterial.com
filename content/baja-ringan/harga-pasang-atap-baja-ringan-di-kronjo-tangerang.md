### Memastikan luas datar

Perhitungan luas datar merupakan ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya yaitu ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yang akan didapat disini yaitu 16.2 x 11.2 dengan hasil luas datar : 181.44 meter.

Penentuan luas miring utk perhitungannya merupakan Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 menciptakan 209.52 meter. Jadi untuk luas kemiringan pada rangka atap baja ringan ini merupakan 209.52 m2.
