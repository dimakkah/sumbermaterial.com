### Menetapkan luas datar

Perhitungan luas datar ialah ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya merupakan ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yg akan didapat disini ialah 16.2 x 11.2 dengan hasil luas datar : 181.44 meter persegi.

### Mempertimbangkan Luas miring

Penentuan luas miring utk perhitungannya ialah Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 menghasilkan 209.52 meter persegi. Jadi untuk luas kemiringan pada rangka atap baja ringan ini ialah 209.52 meter.
