Perhitungan luas datar ialah ( overstack + Panjang ) x ( lebar + overstack ) karenanya hasilya ialah ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yg akan didapat disini merupakan 16.2 x 11.2 dengan hasil luas datar : 181.44 m2.
