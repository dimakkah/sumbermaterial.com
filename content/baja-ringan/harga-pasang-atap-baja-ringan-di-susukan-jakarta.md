Perhitungan luas datar yakni ( overstack + Panjang ) x ( lebar + overstack ) karenanya hasilya yaitu ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yg akan didapatkan disini ialah 16.2 x 11.2 dg hasil luas datar : 181.44 m2.

Penentuan luas miring untuk perhitungannya yaitu Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 menjadikan 209.52 meter persegi. Jadi utk luas kemiringan pada rangka atap baja ringan ini ialah 209.52 meter persegi.
