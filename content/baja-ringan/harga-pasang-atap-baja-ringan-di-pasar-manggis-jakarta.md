### Memastikan luas datar

Perhitungan luas datar ialah ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya merupakan ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Maka hasil yang akan diperoleh disini yakni 16.2 x 11.2 dg hasil luas datar : 181.44 m2.

### Mempertimbangkan Luas miring

Penentuan luas miring untuk perhitungannya yakni Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 menjadikan 209.52 m2. Jadi utk luas kemiringan pada rangka atap baja ringan ini ialah 209.52 meter persegi.
