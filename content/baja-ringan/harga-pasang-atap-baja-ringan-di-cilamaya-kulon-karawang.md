### Memastikan luas datar

Perhitungan luas datar yaitu ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya adalah ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yang akan didapatkan disini yakni 16.2 x 11.2 dengan hasil luas datar : 181.44 meter persegi.

### Menetapkan Luas miring

Penentuan luas miring untuk perhitungannya yakni Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 mewujudkan 209.52 m2. Jadi untuk luas kemiringan pada rangka atap baja ringan ini yakni 209.52 meter.
