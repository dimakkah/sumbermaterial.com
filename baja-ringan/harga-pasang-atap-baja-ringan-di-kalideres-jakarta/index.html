Menghitung Luas Datar

Perhitungan luas datar adalah ( overstack + Panjang ) x ( lebar + overstack ) sehingga hasilnya adalah ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Dengan demikian, hasil yang akan didapatkan adalah 16.2 x 11.2 dengan luas datar : 181.44 m2.

Menghitung Luas Miring

Penentuan luas miring untuk perhitungannya adalah Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44 / 0.8666 menghasilkan 209.52 m2. Jadi, luas kemiringan pada rangka atap baja ringan ini adalah 209.52 meter persegi.
