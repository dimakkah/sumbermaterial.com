Menentukan Luas Datar

Perhitungan luas datar: (overstack + Panjang) x (lebar + overstack) = (15 + 0.6 + 0.6) x (10 + 0.6 + 0.6). Maka hasilnya 16.2 x 11.2 dengan luas datar: 181.44 meter persegi.

Menentukan Luas Miring

Perhitungan luas miring: Luas miring = Luas datar / Cosinus kemiringan atap. Perhitungannya 181.44 / 0.8666 menghasilkan 209.52 meter persegi. Jadi, luas kemiringan pada rangka atap baja ringan ini adalah 209.52 meter persegi.
