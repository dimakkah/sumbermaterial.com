Menentukan Luas Datar

Perhitungan luas datar: (overstack + Panjang) x (lebar + overstack). Contoh: (15 + 0.6 + 0.6) x (10 + 0.6 + 0.6) = 16.2 x 11.2 = 181.44 meter persegi.
