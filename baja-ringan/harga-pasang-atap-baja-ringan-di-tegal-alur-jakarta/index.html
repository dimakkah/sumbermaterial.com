Metode Hitung Luas Rangka Baja Ringan Di Tegal Alur Jakarta

Anda dapat menjalankan perhitungan sendiri jikalau berharap dikerjakan untuk mengetahui harga serta kemiringan atap. Berikut merupakan rumus perhitunganya. Menetapkan kemiringan atap Bila panjang rangka atap sekitar 15 ml, meski utk lebar adalah 10 ml, utk overstack 0.60 m, kemiripan atap sekitar 30 derajat ( cosinus 30 = 0.8660) dg wujud atap limas ( jatuh air dari ke empat sisi ).

Memutuskan luas datar

Perhitungan luas datar ialah ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya yaitu ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Karenanya hasil yg akan diperoleh disini yakni 16.2 x 11.2 dg hasil luas datar : 181.44 meter persegi.

Memutuskan Luas miring

Penentuan luas miring untuk perhitungannya merupakan Luas miring = Luas datar / Cosinus dg kemiringan atap. Perhitungannya 181.44/0.8666 menciptakan 209.52 m2. Jadi untuk luas kemiringan pada rangka atap baja ringan ini adalah 209.52 m2.

Dengan begitu anda bisa memastikan jumlah dan volume baja ringan utk pemesangan, namun jika tampak sulit utk dijalankan.
