Menentukan Luas Datar

Perhitungan luas datar adalah (overstack + Panjang) x (lebar + overstack). Contoh: (15 + 0.6 + 0.6) x (10 + 0.6 + 0.6) = 16.2 x 11.2 = 181.44 m2.

Mempertimbangkan Luas Miring

Penentuan luas miring: Luas miring = Luas datar / Cosinus kemiringan atap. Contoh: 181.44 / 0.8666 = 209.52 m2 (dengan kemiringan atap 30 derajat). Jadi, luas kemiringan pada rangka atap baja ringan adalah 209.52 meter persegi.
