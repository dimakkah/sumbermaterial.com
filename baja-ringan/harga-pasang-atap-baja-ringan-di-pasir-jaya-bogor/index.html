Menetapkan kemiringan atap Jika panjang rangka atap sekitar 15 ml, sedangkan utk lebar ialah 10 ml, utk overstack 0.60 m, kemiripan atap sekitar 30 derajat ( cosinus 30 = 0.8660) dg format atap limas ( jatuh air dari ke empat sisi ).

Menentukan luas datar

Perhitungan luas datar ialah ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya merupakan ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Maka hasil yg akan diperoleh disini ialah 16.2 x 11.2 dg hasil luas datar : 181.44 meter.

Mempertimbangkan Luas miring

Penentuan luas miring untuk perhitungannya ialah Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 menjadikan 209.52 meter. Jadi untuk luas kemiringan pada rangka atap baja ringan ini merupakan 209.52 meter.

Dengan begitu anda dapat menentukan jumlah dan volume baja ringan utk pemesangan, tapi jika tampak sulit utk dilaksanakan.
