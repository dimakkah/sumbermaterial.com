Metode Hitung Luas Rangka Baja Ringan Di Tambora Jakarta

Anda bisa menjalankan perhitungan sendiri apabila mau dilakukan utk mengetahui biaya serta kemiringan atap. Berikut ialah rumus perhitunganya. Menetapkan kemiringan atap Seandainya panjang rangka atap sekitar 15 ml, padahal untuk lebar adalah 10 ml, untuk overstack 0.60 m, kemiripan atap sekitar 30 derajat ( cosinus 30 = 0.8660) dg wujud atap limas ( jatuh air dari ke empat sisi ).

Memutuskan luas datar

Perhitungan luas datar adalah ( overstack + Panjang ) x ( lebar + overstack ) maka hasilya ialah ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Maka hasil yg akan didapat disini ialah 16.2 x 11.2 dg hasil luas datar : 181.44 m2.

Memutuskan Luas miring

Penentuan luas miring utk perhitungannya merupakan Luas miring = Luas datar / Cosinus dengan kemiringan atap. Perhitungannya 181.44/0.8666 mewujudkan 209.52 meter persegi. Jadi untuk luas kemiringan pada rangka atap baja ringan ini yaitu 209.52 m2.

Dengan seperti itu anda bisa menetapkan jumlah dan volume baja ringan untuk pemesangan, melainkan apabila kelihatan sulit untuk dikerjakan.
