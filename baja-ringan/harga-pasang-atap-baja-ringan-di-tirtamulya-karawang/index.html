Cara Hitung Luas Rangka Baja Ringan Di Tirtamulya Karawang

Anda bisa mengerjakan perhitungan sendiri kalau mau dilaksanakan untuk mengetahui biaya serta kemiringan atap. Berikut adalah rumus perhitunganya. Memastikan kemiringan atap Apabila panjang rangka atap sekitar 15 ml, walaupun untuk lebar merupakan 10 ml, untuk overstack 0.60 m, kemiripan atap sekitar 30 derajat ( cosinus 30 = 0.8660) dengan bentuk atap limas ( jatuh air dari ke empat sisi ).

Memastikan luas datar

Perhitungan luas datar yaitu ( overstack + Panjang ) x ( lebar + overstack ) karenanya hasilya ialah ( 15 + 0.6 + 0.6 ) x ( 10 + 0.6 + 0.6 ). Maka hasil yg akan diperoleh disini adalah 16.2 x 11.2 dg hasil luas datar : 181.44 meter.

Menentukan Luas miring

Penentuan luas miring untuk perhitungannya adalah Luas miring = Luas datar / Cosinus dg kemiringan atap. Perhitungannya 181.44/0.8666 mewujudkan 209.52 meter persegi. Jadi untuk luas kemiringan pada rangka atap baja ringan ini yakni 209.52 meter.

Dengan demikian itu anda bisa memastikan jumlah dan volume baja ringan utk pemesangan, namun kalau menonjol susah utk dikerjakan.
