Menghitung Luas Datar

Luas datar = (overstack + Panjang) x (lebar + overstack) = (15 + 0,6 + 0,6) x (10 + 0,6 + 0,6). Hasilnya adalah 16,2 x 11,2, sehingga luas datar: 181,44 meter persegi.

Menghitung Luas Miring
